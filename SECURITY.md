# Security Policy

## Supported Versions

This project is currently pre-1.0. Security fixes are applied to the latest
development branch and the latest `v0.1.x` release.

| Version | Supported |
| --- | --- |
| `flutter-engineers` (development) | :white_check_mark: |
| `v0.1.x` | :white_check_mark: |
| `< v0.1.0` | :x: |

## Reporting a Vulnerability

Please do not report security vulnerabilities in a public issue or discussion.
Use [GitHub's private vulnerability reporting](https://github.com/AymanYehia23/ekb-toolkit/security/advisories/new)
instead.

Include:

- the affected version or commit;
- a clear description of the vulnerability and its impact;
- steps to reproduce it using the fictional example workspace where possible;
- any proposed mitigation or patch.

Do not include credentials, private repository contents, personal career data,
or other sensitive information in the report.

There is no guaranteed response time. The maintainers will review valid reports
privately, provide updates as the assessment progresses, and coordinate a fix
or explain why the report is not accepted when possible.
